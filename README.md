# ai-architect-lab

My lab repo for a 10-month AI Solution Architect program (Oct 2026 - Jul 2027).

## Course goal
Become an AI Solution Architect on Azure, building in both C# and Python.
I learn by building small labs, measuring results with numbers, and writing down
my design decisions.

## Rules for this repo
- No API keys or secrets in code. Use keyless auth (Entra ID, `DefaultAzureCredential`).
- Use free tiers first. Pay only when there is no free option.
- Every lab has a short note in `LEARNING-LOG.md`.

## Structure
- `LEARNING-LOG.md` - what I learned in each lesson
- `labs/` - one folder per lab
